libexif is a library for parsing, editing, and saving EXIF data. It is intended to replace lots of redundant implementations in command-line utilities and programs with GUIs.

## Features

- Read and write EXIF data from/to JPEG and TIFF files
- Support for all EXIF tags as defined in the EXIF 2.2 specification
- Built-in support for camera maker notes for many camera models
- Flexible API for both simple and advanced usage
